# Dakota Coffee ☕

A cozy, modern coffee shop website for **Dakota Coffee** — a fictional cafe brand. Designed to feel warm and inviting, with a focus on clean typography and an approachable layout.

## Stack

| | |
|---|---|
| Framework | React + TypeScript |
| Styling | Tailwind CSS + shadcn/ui |
| Build | Vite |

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
